COMO CONECTAR QUALQUER APP NA CENTRAL MALHACORE

O MalhaCore inclui um SDK universal sem dependências externas em sdk/malhacore_client.py. Copie o arquivo para a raiz do seu aplicativo e inicialize:

OPÇÃO A: APLICATIVO FLASK (EX: 01.SHIRLEI) 
from malhacore_client import MalhaCoreMonitor

# Inicializa o monitor e conecta ao Flask com 1 comando
monitor = MalhaCoreMonitor(
    app_slug="01-clinicas", 
    app_nome="01.Clínicas — Dra. Shirlei Elisabete",
    server_url="http://127.0.0.1:8000"  # ou URL da sua VPS/Central
)
monitor.init_flask(app, cliente_padrao="Dra. Shirlei Elisabete")
# Pronto! Captura acessos, tempos de resposta, usuários autenticados e exceções 500 sem travar o app.
OPÇÃO B: QUALQUER PYTHON / SCRIPTS / FASTAPI 
from malhacore_client import MalhaCoreMonitor

monitor = MalhaCoreMonitor(app_slug="meu-app-exemplo", server_url="http://127.0.0.1:8000")

# Capturar erros manuais em qualquer bloco de código:
try:
    executar_rotina()
except Exception as erro:
    monitor.capturar_excecao(erro, cliente="Cliente Alfa", rota="/processar")

# Registrar acessos manuais:
monitor.registrar_acesso(rota="/login", usuario="usuario@email.com", status_code=200)
Registro Automático: Não é necessário pré-cadastrar o aplicativo no banco. Ao enviar o primeiro acesso, erro ou ping, o MalhaCore cataloga o app instantaneamente na central. Se possuir uma URL pública, adicione-a no cadastro para habilitar o botão [ CHECAR ONLINE ].
